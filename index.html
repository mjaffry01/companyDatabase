This page talks to your spreadsheet through a small Apps Script bridge. One-time setup:

  1. Open your Jobfinder spreadsheet → Extensions → Apps Script.
  2. Paste in the Code.gs script, save.
  3. Click Deploy → New deployment → type Web app. Set Execute as: Me, Who has access: Anyone.
  4. Copy the Web app URL (ends in /exec) and paste it below.
